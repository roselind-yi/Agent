# PRD - 个人智能助理 Agent

## 背景

个人用户在知识查询、日程安排和生活信息查询上存在大量碎片化需求。传统聊天机器人容易泛化回答，缺少执行链路和结果可解释性。本项目希望验证一个小而完整的个人 Agent：能检索个人知识、调用基础工具，并把执行过程透明返回。

## 目标用户

- 需要管理学习、面试、项目资料的个人用户。
- 希望用自然语言完成轻量工具操作的用户。

## 核心场景

1. 知识库问答：询问项目定位、Prompt 结构、RAG 原理、竞品分析结论。
2. 日程管理：查询今天或明天的安排，创建简单日程。
3. 生活查询：查询城市天气、执行简单计算。

## MVP 范围

- 支持 `/chat` 单入口。
- 支持知识库检索和引用。
- 支持计算器、日程、天气 3 个工具。
- 支持执行 trace，便于调试和面试讲解。
- 支持 Java 客户端调用。

## 非目标

- 不做复杂多轮记忆系统。
- 不接入真实用户隐私日历。
- 不追求大而全的插件市场。

## 成功指标

- 主要问题能被正确路由到 RAG 或工具。
- 输出包含明确答案、引用或工具结果。
- 面试现场能在 3 分钟内完成演示闭环。
