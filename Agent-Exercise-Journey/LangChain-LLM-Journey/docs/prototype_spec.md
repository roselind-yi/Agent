# 高保真原型说明

本项目的高保真原型已落地在 `web/index.html`，可通过浏览器访问：

```text
http://127.0.0.1:8765/chat
```

## 原型页面结构

- 左侧导航：展示 Agent 的核心能力模块和面试亮点。
- 顶部信息：展示项目名称、场景范围和运行状态。
- 中央对话区：支持自由输入，也支持示例问题快捷触发。
- 右侧信息区：展示最近工具调用、知识库引用和执行 Trace。

## 对应简历表述

- “知识库问答”：通过产品定位、Prompt 分层、RAG、竞品分析等知识文档召回。
- “日程管理”：通过 CalendarTool 查询演示日程。
- “生活查询”：通过 WeatherTool 和 CalculatorTool 完成天气、计算。
- “任务拆解 -> 工具调用 -> 反思修正”：通过意图识别、tool/citation/trace 可视化展示。
- “FastAPI 服务接口 + Java 客户端”：分别在 `app/main.py` 和 `java-client` 中实现。
