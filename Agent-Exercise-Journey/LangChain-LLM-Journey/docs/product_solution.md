# 产品方案设计

## 产品定义

Journey Personal Agent 是一个面向个人用户的智能助理。它不追求“万能聊天”，而是围绕三类明确需求提供可执行闭环：

- 知识库问答：从个人资料、项目文档、面试材料中检索答案。
- 日程管理：查询今天/明天安排，创建轻量日程。
- 生活查询：计算、天气等高频工具调用。

## 用户旅程

1. 用户用自然语言提出问题。
2. Agent 判断是知识问答、工具调用，还是二者组合。
3. 知识类问题进入 RAG 检索，工具类问题进入 Tool Router。
4. 生成回答时展示结果、引用、执行 trace。
5. 用户根据答案继续追问或执行下一步。

## 功能模块

| 模块 | 用户价值 | 当前实现 |
| --- | --- | --- |
| 对话入口 | 降低使用门槛 | Web Demo + `/chat` API |
| RAG 知识库 | 私有资料可问答 | LocalVectorStore，预留 ChromaDB adapter |
| 工具调用 | 从回答走向执行 | 计算器、日程、天气 |
| Trace 可解释 | 支持调试和信任建立 | 每轮返回 classify、tool、retrieval、generate |
| Java 联调 | 展示工程对接能力 | JDK `HttpClient` 客户端 |

## 体验原则

- 先给结论，再给依据。
- 工具结果与知识库引用分开展示。
- 对演示数据保持透明，不伪装真实外部服务。
- 面试场景优先保障离线可运行。
