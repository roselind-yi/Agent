# 竞品分析

## 结论摘要

| 产品 | 优势 | 不足 | 对本项目启发 |
| --- | --- | --- | --- |
| Coze | 可视化编排、插件生态、发布链路完整 | 高级能力受平台约束，私有化与深度定制成本高 | 学习其低门槛编排与插件心智 |
| Dify | 企业知识库、工作流、模型接入成熟 | 对个人轻量场景略重 | 学习其 RAG 配置和可观测能力 |
| LangChain | 开发者生态强，链式编排灵活 | 产品化体验需自行搭建 | 用作底层编排思想和工程结构参考 |

## 产品机会

个人智能助理不需要追求“什么都能做”，更适合从高频任务闭环切入：

- 个人知识库问答：让用户快速找到自己的资料。
- 日程和生活工具：让 Agent 从回答走向执行。
- Trace 透明：让用户知道系统为何这样回答，降低不信任。

## 本项目定位

本项目把边界收敛为知识库问答、日程管理、生活查询三类需求，并通过 Prompt 分层和工具路由实现可解释的 Agent 执行链路。
